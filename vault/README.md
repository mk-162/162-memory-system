# Memory Vault

This is the root of your persistent memory system.

All project decisions, context, status, and processes are stored here as structured Obsidian notes.

## How to work with this vault

- Use the Obsidian skills for every edit
- Trigger Phoebe mode when you need documented answers
- Keep one project note per active piece of work in the `projects/` folder

See `meta/README.md` for core rules and `SETUP.md` (in the repo root) for initial setup.
