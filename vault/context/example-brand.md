# Example Brand Voice

**Tone**: Direct, confident, and jargon-free.

**Positioning style**: Problem-first and outcome-first. Never lead with features.

**Do**:
- Use concrete examples
- Speak like a smart colleague
- Focus on results and trade-offs

**Don't**:
- Use buzzwords without explanation
- List features without connecting them to outcomes
