# Meta

This folder contains instructions for using and maintaining the vault.

## Core Rules

- Every active project gets exactly one note in `projects/`
- Use frontmatter for status, tags, and key dates
- Keep context facts in `context/` — do not duplicate them in project notes
- When editing notes, always use the Obsidian skills (`obsidian-markdown`, `obsidian-bases`, etc.)
- Trigger Phoebe mode (`Phoebe:` or `phi:`) when you want answers grounded only in this vault

## Recommended Obsidian Plugins

- Dataview (or use the built-in Bases)
- Periodic Notes
- Templater (optional but powerful)
