# Obsidian Skills

**Source**: https://github.com/kepano/obsidian-skills

These skills ensure consistent, correct use of Obsidian syntax across all notes.

## Core Skills

- `obsidian-markdown` — Frontmatter, wikilinks, callouts, embeds
- `obsidian-bases` — Database views, filters, and formulas
- `obsidian-cli` — Terminal interaction with the vault
- `json-canvas` — Visual boards and maps

## Usage Rule

Always use these skills when creating or editing notes in this vault. Do not write raw Obsidian syntax manually.
