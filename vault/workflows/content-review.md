# Content Review Workflow

1. Read the relevant brief and brand guidelines from `context/`
2. Write the first draft
3. Run the draft through the review checklist in this note
4. Request feedback with specific questions
5. Apply changes and update the project note

## Review Checklist

- [ ] Problem-first framing used
- [ ] No unexplained jargon
- [ ] Concrete examples included
- [ ] Outcome clearly stated
